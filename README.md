# Aptos Balance Checker

Инструмент для проверки баланса APT токенов на кошельках Aptos.

## Установка

```bash
npm install
```

## Настройка

### Для проверки балансов:
1. Создайте файл `wallets.txt` в корневой директории проекта
2. Добавьте адреса кошельков для проверки (по одному на строку)
3. Пример: `0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef`

### Для трансфера средств:
1. Создайте файл `keys.txt` в корневой директории проекта
2. Добавьте приватные ключи кошельков (по одному на строку)
3. Создайте файл `sub_accs.txt` для субаккаунтов (по одному на строку)

## Запуск

### Разработка
```bash
npm run dev
```

### Продакшн
```bash
npm run build
npm start
```

## Структура проекта

- `src/` - исходный код TypeScript
- `dist/` - скомпилированный JavaScript код
- `wallets.txt` - адреса кошельков для проверки балансов
- `keys.txt` - приватные ключи кошельков для трансфера
- `sub_accs.txt` - субаккаунты для трансфера

## Безопасность

⚠️ **Внимание**: Файлы `keys.txt`, `sub_accs.txt` и `wallets.txt` содержат конфиденциальные данные и не должны попадать в публичные репозитории.
